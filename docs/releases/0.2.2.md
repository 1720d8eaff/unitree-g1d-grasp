# Version 0.2.2

Laptop AnyGrasp startup compatibility fix.

## Fixed

- The supervised AnyGrasp server now changes to
  `/home/yii/anygrasp_sdk/grasp_detection` before loading the network. The
  proprietary license loader resolves `licenseCfg.json` relative to the
  current working directory, matching the established manual startup command.

## Deployment

- Laptop project files only; no board update or restart is required.

## Safety

- ARM and real trajectory execution remain forbidden by both supervisor
  configurations.
- A failed AnyGrasp startup still stops all laptop-side supervised children.
