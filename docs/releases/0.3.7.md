# Version 0.3.7

Explicit reviewed RH56H1 grasp cycle for a saved full trajectory.

- `--execute-saved --grasp-cycle` first plans and collision-checks a Cartesian
  5 cm lift along `torso_link` +Z, then publishes the main path and lift
  together for RViz review.
- After the exact per-run confirmation, PREOPEN is acknowledged before arm
  motion and CLOSE begins one second before the main path's nominal endpoint.
- The close timer is anchored to the board's observed `executing` status, not
  to the earlier MoveIt request time.
- CLOSE reuses the object-width acknowledgement obtained by PREOPEN, so the
  timed callback sends the close command directly instead of repeating the
  width handshake at the endpoint.
- The main endpoint and lift start must pass fresh measured-joint acceptance
  before the lift is sent; the lift endpoint is checked afterwards.
- A lift artifact already present in the run directory is never overwritten;
  another attempt requires a fresh Plan-only run.
- Timed CLOSE failures do not interrupt the moving arm mid-path, but they stop
  the subsequent lift and are reported as failures.
- No ARM, DISARM, or RELEASE command is present. Existing plan-only, arm-only,
  and legacy `--execute --with-hand` paths remain separate.
