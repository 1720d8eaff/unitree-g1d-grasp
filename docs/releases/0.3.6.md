# Version 0.3.6

Exact saved-full-trajectory execution entry point.

- `--execute-saved` deserializes the CDR in `G1D_RUN_DIR` without replanning.
- SHA-256, artifact type, point count, joint order, current start, PlanningScene,
  per-point collision, live target, relay timing, and endpoint checks remain
  mandatory.
- A known combined reversal above `0.30 rad` requires the explicit
  `--accept-known-combined-reversal` acknowledgement and an interactive phrase.
- No ARM/DISARM, RH56H1 command, lift, or automatic continuation is included.
