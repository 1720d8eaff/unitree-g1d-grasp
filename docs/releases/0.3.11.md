# Version 0.3.11

Live AnyGrasp pose restored as the source of every second-stage grasp goal.

- Replaces the temporary absolute `torso_link` manual-TCP target with a
  calibrated AnyGrasp-to-TCP relative transform.
- Applies the relative transform to the single fresh, stable candidate-A pose
  frozen for each plan, so both target translation and rotation follow the
  currently detected object.
- Keeps the reviewed manual endpoint joint vector as a deterministic IK seed
  and retains the `-5..+5` degree final wrist-yaw constraint and
  `-10..+30` degree approach envelope.
- Marks older saved paths without the live-relative target mode as stale and
  refuses real execution until a new Plan-only run is generated and reviewed.
- Preserves collision, physical joint-limit, path-shape, Cartesian-completeness,
  start-state, live-target drift, endpoint and RViz review gates.
