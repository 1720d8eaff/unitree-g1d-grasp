# Version 0.3.9

Read-only full-motion calibration recorder with AnyGrasp-segment extraction.

- The original taught trajectory, source recording, and recorder are unchanged.
- `./g1dctl teach-calibrate` records the complete manually guided motion from
  the hanging-arm state to the accepted TCP grasp pose.
- The analyzer finds the sample closest to the existing taught endpoint and
  uses it as the first/second-segment seam. It reports both the full motion and
  extracted second segment while marking only second-segment values for planner
  tuning.
- The report includes per-joint endpoints, ranges, total variation, reversal
  detours, direction changes, sample steps, velocities, a sampled FK TCP path,
  and comparison with the latest AnyGrasp target when available.
- The recorder contains no publisher, action client, ARM/DISARM client,
  trajectory command, or hand command. It never applies gate changes itself.
