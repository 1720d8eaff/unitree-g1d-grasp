# 0.3.14 — one terminal per machine for the RH56H1 chain

- Added a separate `g1d-hand-laptop-start` command for the laptop UDP-to-RS485
  gateway; it is not part of `g1d-laptop-start`.
- Added a separate `g1d-hand-board-start` command that combines the board UDP
  driver, virtual-gripper mapper, and virtual-gripper controller in one
  foreground terminal; it is not part of `g1d-board-start`.
- Added one board Foxy/Cyclone environment helper so all three hand services
  run from the project-pinned sources without mixing with the vision Conda
  environment.
- Added readiness checks, per-process logs, and fail-together shutdown through
  the existing foreground supervisors.
- Startup still does not ARM, move the robot, or send PREOPEN/CLOSE/RELEASE.
