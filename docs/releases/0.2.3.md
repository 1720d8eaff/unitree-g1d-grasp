# Version 0.2.3

Deterministic AnyGrasp SDK module selection.

## Fixed

- The AnyGrasp server now promotes the configured SDK root to the front of
  Python's module search path. The Conda environment already contained the SDK
  root later in `PYTHONPATH`, so version 0.2.2 did not move it ahead of the
  incompatible `gsnet_versions` directory.
- Startup prints the resolved `gsnet` module path for direct diagnosis.
- The AnyGrasp child uses unbuffered Python output, so the supervisor observes
  the readiness marker immediately instead of waiting for a full stdout buffer.
- Visualization remains enabled for normal startup and can be disabled with
  `ANYGRASP_SHOW_VISUALIZATION=0` for a headless service check.

## Expected startup evidence

- license file check reports `passed`;
- resolved module path is under `/home/yii/anygrasp_sdk/grasp_detection/gsnet`;
- it must not resolve from `grasp_detection/gsnet_versions`.

## Deployment

- Laptop project files only; no board update or restart is required.

## Safety

- ARM and real trajectory execution remain forbidden by both supervisor
  configurations.
