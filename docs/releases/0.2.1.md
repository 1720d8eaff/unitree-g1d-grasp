# Version 0.2.1

Compatibility fix for the two-command supervisors.

## Fixed

- ROS Foxy, ROS Humble, and Conda setup files are now loaded without shell
  `nounset`. Foxy reads optional variables such as `AMENT_TRACE_SETUP_FILES`,
  so `set -u` caused the board control process to exit before startup.
- The same compatible environment-loading rule is applied to all board and
  laptop child-process commands.

## Safety

- ARM and real trajectory execution remain forbidden by both supervisor
  configurations.
- RH56H1 remains excluded from automatic startup.
- Planning remains blocked until the raised-column table geometry is measured
  and verified.
