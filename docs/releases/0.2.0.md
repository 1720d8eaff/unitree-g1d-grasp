# Version 0.2.0

Released as the first two-command supervised project layout.

## Added

- `g1d-board-start` for the isolated board control and D435 processes.
- `g1d-laptop-start` for the isolated MoveIt, AnyGrasp, and selector processes.
- foreground supervision, prefixed live output, per-process logs, duplicate
  supervisor locking, readiness patterns, and targeted process-group cleanup.
- a board transfer archive builder and SHA-256 sidecar.
- pending handoff-manual update notes.

## Safety

- both process configurations explicitly forbid ARM and real execution;
- no RH56H1 process starts by default;
- Plan-only remains blocked while the raised-column table geometry is
  unverified;
- any required child exit stops the rest of that machine's supervised stack.
