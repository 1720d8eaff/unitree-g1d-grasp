# Version 0.3.4

Strict final-approach preview safety release.

## Changed

- keep the current live AnyGrasp orientation in the consolidated Plan-only
  pipeline instead of silently substituting the historical verified reference;
- forbid automatic IK roll relaxation for the overhead and final approach;
- enforce the `left_wrist_yaw_joint` `[-30 deg, 0 deg]` bound at every point
  of both the overhead transfer and the final Cartesian descent;
- require both individual-stage detour and the combined overhead-to-descent
  waypoint reversal to remain at or below `0.30 rad`;
- record the strict-orientation and allowed-roll policies in each plan's JSON
  metadata.
- evaluate up to four distinct collision-free IK branches for the same live
  target instead of retrying only the nearest branch, and log the joint that
  limits each detour/reversal score.

## Safety

- these changes affect planning and RViz preview only;
- `g1dctl` still exposes no real execution, ARM/DISARM, or hand command;
- a target without an exact-orientation, low-reversal solution is rejected.
