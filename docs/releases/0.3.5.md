# Version 0.3.5

Previous-planner comparison preview release.

## Added

- `g1dctl plan --previous-preview` restores the last known planning policy for
  RViz comparison while keeping the entire command Plan-only;
- the generated metadata marks whether the previous policy was used and
  whether the combined-reversal gate was enforced.

## Previous-preview policy

- permit verified-orientation fallback after a live AnyGrasp branch jump;
- restore the former IK roll-relaxation search;
- select the nearest bounded wrist-yaw IK branch;
- use the former per-stage detour gate without rejecting on the combined
  overhead-to-descent reversal score.

## Safety

- the compatibility switch is opt-in and applies only to planning/RViz;
- `g1dctl` still exposes no real execution, ARM/DISARM, or hand command;
- strict planning remains the default when the switch is omitted.
