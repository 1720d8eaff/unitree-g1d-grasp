- Keeps the 0.3.11 live AnyGrasp to relative taught-TCP target calculation.
- Replaces the workspace-wide `-5..+5` degree final wrist-yaw hard constraint
  with the reviewed `-10..+30` degree envelope used by the approach.
- Retains the taught `+1.0719` degree endpoint as a deterministic IK seed. It
  is no longer treated as proof that every live target must finish near zero.
- Does not relax TCP pose, collision, mechanical joint limits, trajectory
  shape, Cartesian completeness, start-state, target-drift or RViz gates.
- Requires a new Plan-only run; saved paths from earlier target policies remain
  rejected by the live-relative target-mode gate.
