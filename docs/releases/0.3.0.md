# Version 0.3.0

Project-specific script collection release.

## Added

- project-owned laptop control and MoveIt launchers;
- current MoveIt config and active URDF sources;
- current installed laptop relay source, replacing the stale collected copy;
- complete RH56H1 UDP driver ROS package from the retained transfer archive;
- retained board state/startup and height-control reference sources;
- a read-only board script exporter and an explicit script inventory.

## Runtime change

- `g1d-laptop-start` now calls the collected project-owned laptop control
  launcher, which calls the adjacent project-owned MoveIt launcher. Installed
  ROS packages and environments remain external dependencies.

## Safety

- no ARM, DISARM, trajectory execution, height command, or hand command was
  added to either automatic startup path;
- exact live-board sources are collected only by an explicit read-only export;
- Plan-only remains blocked until the raised-column table geometry is measured.
