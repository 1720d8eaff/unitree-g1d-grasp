# Version 0.3.13

Live target position is separated from the taught grasp orientation.

- Uses the fresh stable candidate-A position for every Plan-only run and adds
  only the measured world-frame TCP position bias from the teach calibration.
- Uses the manually accepted palm orientation instead of rotating the complete
  calibration with AnyGrasp orientation jitter.
- Restores the operator-requested `-5..+5` degree final wrist-yaw constraint;
  the unsuccessful 0.3.12 widening is not retained.
- Keeps the taught endpoint as an IK seed and the `-10..+30` degree envelope
  for overhead transfer and Cartesian descent.
- Invalidates earlier saved plans through a new planner-policy identifier.
- Preserves collision, mechanical joint-limit, trajectory-shape, Cartesian,
  start-state, live-target drift, endpoint and RViz review gates.
